Indicadores Logísticos



Esta sección reúne los principales KPIs utilizados para medir el desempeño de la operación logística.





Objetivos



Monitorear la operación.

Detectar oportunidades de mejora.

Facilitar la toma de decisiones.





Indicadores clave



**Inventarios**

Rotación de inventario.

Cobertura.

Exactitud.



**Compras**

Lead Time.

Cumplimiento de proveedores.

Ahorro en compras.



**Distribución**

OTIF.

Tiempo de entrega.

Eficiencia de transporte.

Excel

Power BI

SQL
